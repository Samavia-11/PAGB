## 1. Introduction

This document specifies **feature-wise test cases** for the PAGB Landing Website. Each test case includes:

- Test Case ID
- Feature / Module
- Description
- Preconditions

- Status (Pass/Fail, to be completed during execution)

## 8. Security Test Cases

| ID       | Feature           | Description                                         | Preconditions                                             | Steps                                                                                                                                          | Test Data / Input                                           | Expected Result                                                                                                 | Actual Result (to be completed) | Status (Pass/Fail) |
|----------|-------------------|-----------------------------------------------------|-----------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|-------------------------------|---------------------|

| TC-SC-02 | Rate Limiting     | Limit excessive API calls from single client       | Application running                                      | 1. | TC-SC-03 | RBAC Enforcement  | Prevent low-privilege user from changing article   | Article belongs to another author; low-privileged user   | 1. Log in as user who is not the article’s author  2.
